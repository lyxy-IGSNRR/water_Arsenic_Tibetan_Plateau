# water_Arsenic_Tibetan_Plateau
The code is expected to provide sufficient information to reproduce the study. 
This code is public available.
The code, together with the paper (Natural surface water Arsenic threat throughout the Tibetan Plateau) and dataset (https://zenodo.org/records/24122792), report preprocessing procedures, missing-data treatment, outlier treatment, encoding procedures, normalization/standardization, data splitting, random seeds, hyperparameters, feature-selection procedure, cross-validation strategy.
